# Roteiro rápido de apresentação

1. Mostrar a tela Início e o BottomNavigation.
2. Abrir Categorias, cadastrar “Transporte” e mostrar o ID.
3. Abrir Despesas, cadastrar uma passagem com o ID criado.
4. Abrir o detalhe da despesa, alterar o valor e salvar.
5. Abrir o detalhe da categoria e demonstrar o total calculado.
6. Mostrar Relatórios.
7. Excluir uma despesa e confirmar que a lista foi atualizada.
8. Fechar completamente o aplicativo e abrir novamente para demonstrar a persistência do Room.

Antes de apresentar, o trio deve executar este roteiro no próprio emulador/dispositivo e capturar as telas reais.
